# Privacy

Amanat keeps a list, on this phone, of who is holding your originals.

- The list sits in a local database on the device. It is not sent to a server. There isn’t one.
- A receipt photo, if you add one, is scaled down on the phone and stored the same way. The app asks you not to photograph the document itself. It cannot stop you if you do.
- A backup file is created only when you download it. Restoring a backup reads a file you chose.
- An unlock code is checked on the device with a public key. The app does not phone home to ask whether you paid.
- The license desk does not store or transmit the private key you paste into it.
- A UPI link, if the owner configured one, opens your payment app. Amanat does not see the payment.

If you clear the site’s data, the list is gone. Download a backup first if you meant to keep it.
